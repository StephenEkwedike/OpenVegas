OpenVegas puts optional games and $V-funded AI usage alongside the coding tools you already use.

See how to play

One balance. Your choice.

  • Buy $V when you need credits.
  • Play a game if you want to risk some.
  • Use available $V for separately billed AI requests.

No guaranteed winnings. No subscription refill.

Connect once.

npx openvegas-ai
  • Have Node.js/npm and Claude Code or Codex installed.
  • Sign in to OpenVegas and approve the integration. Match the browser code to your terminal.
  • Use the configured terminal for game graphics and the wallet strip. After installation, start a fresh claude or codex session there.

Native features require a compatible OpenVegas release and enabled backend. Older published builds may not include every feature yet.

Play in place.

Pick a game, submit your stake, then return to your project. No second coding environment.

$openvegas play

Inside your connected host

openvegas use v
  • Review model pricing and confirm a session spending limit before starting.
  • OpenVegas routes supported API usage through its backend. No personal provider key needed.
  • Return with openvegas use host.

Provider and feature availability apply. This requires the connected OpenVegas terminal integration; a disconnected session cannot switch billing. Switching may briefly restart and resume the same conversation. This does not refill Claude or ChatGPT subscription quotas. Native subscription billing stays unchanged until you choose another mode.
