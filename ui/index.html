Walk through setup

Before you start

What do I need?

Node.js/npm and an installed Claude Code or Codex CLI. Native features require a compatible OpenVegas release and enabled backend; older published builds may not include them yet.

Animations depend on your host version and graphics terminal. Text controls or a separate companion pane are the fallback.

Check setup and compatibility
Does this change my AI billing?

Your native subscription billing stays unchanged. OpenVegas does not refill Claude Code or Codex subscription limits. Your host stays in charge of coding, tools and permissions.

Separately funded inference uses $V only where enabled. Review model pricing and confirm a spending limit before starting.

Understand separate AI funding
What about games and credits?

Games are optional. Wagers can lose credits; there are no guaranteed earnings or cheaper AI. Coding activity does not earn $V rewards.
